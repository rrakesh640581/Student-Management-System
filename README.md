# Student Management System

## Project Overview
The Student Management System is a web application developed using Python and Django. It helps users manage student information easily and securely.

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- Chart.js

## Features
- User Registration and Login
- Add Student Records
- View Student Details
- Edit Student Information
- Delete Student Records
- Search Students by Name and Email
- Filter Students by Course
- Dashboard with Student Statistics
- Interactive Charts
- User-Based Data Access Control

## Installation and Setup

1. Clone this repository:

   `git clone https://github.com/rrakesh640581/Student-Management-System.git`

2. Open the project folder.

3. Create a virtual environment:

   `python -m venv venv`

4. Activate the environment on Windows:

   `venv\Scripts\activate`

5. Install dependencies:

   `pip install -r requirements.txt`

6. Apply migrations:

   `python manage.py migrate`

7. Start the server:

   `python manage.py runserver`

8. Open your browser:

   `http://127.0.0.1:8000/`
